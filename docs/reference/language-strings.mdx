## Language Strings

All user-facing text is defined in `strings.psd1`. The module ships defaults for 25 languages;
English lives in the root of the `Strings` folder and other languages in their own subfolders. A
deployment overrides them by supplying its own `Strings\strings.psd1`.

The active string table is available to scripts through
[`Get-ADTStringTable`](./functions/Get-ADTStringTable.mdx). The language is selected from the
operating system unless `UI.LanguageOverride` is set; see
[Configuration Settings](./config-settings.mdx).

String values support markup, as described in [Text Formatting](./text-formatting.mdx).

## Close prompts

| Setting                      | Description                                  |
| :--------------------------- | :------------------------------------------- |
| `ClosePrompt.ButtonClose`    | Button text for closing the prompt.          |
| `ClosePrompt.ButtonContinue` | Button text for continuing the close prompt. |
| `ClosePrompt.ButtonDefer`    | Button text for deferring the close prompt.  |

| `Progress.MessageRepairDetail`    | Detailed message displayed during repair.         |
