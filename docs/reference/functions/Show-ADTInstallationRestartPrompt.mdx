## SYNOPSIS

Displays a restart prompt with a countdown to a forced restart.

## SYNTAX

### InteractiveCountdown (Default)

```powershell
Show-ADTInstallationRestartPrompt [-InteractiveCountdown <TimeSpan>] [-InteractiveCountdownNoHide <TimeSpan>]
 [-ShutdownReasonText <String>] [-NoForceCloseApps] [-AllowMove] [-AllowCancel] [-CustomMessage]
 [-CustomMessageText <String>] [-NotTopMost] [-PersistPrompt] [-WindowLocation <DialogPosition>] [-Force]
 -Title <String> -Subtitle <String> [<CommonParameters>]
```

### InteractiveCountdownAllowSilentRestart

```powershell
Show-ADTInstallationRestartPrompt [-InteractiveCountdown <TimeSpan>] [-InteractiveCountdownNoHide <TimeSpan>]
 [-AllowSilentRestart] [-SilentCountdown <TimeSpan>] [-ShutdownReasonText <String>] [-NoForceCloseApps]
 [-AllowMove] [-AllowCancel] [-CustomMessage] [-CustomMessageText <String>] [-NotTopMost] [-PersistPrompt]
 [-WindowLocation <DialogPosition>] [-Force] -Title <String> -Subtitle <String> [<CommonParameters>]
```

### NoInteractiveCountdownAllowSilentRestart

```powershell
Show-ADTInstallationRestartPrompt [-NoInteractiveCountdown] [-AllowSilentRestart] [-SilentCountdown <TimeSpan>]
 [-ShutdownReasonText <String>] [-NoForceCloseApps] [-AllowMove] [-AllowCancel] [-CustomMessage]
 [-CustomMessageText <String>] [-NotTopMost] [-PersistPrompt] [-WindowLocation <DialogPosition>] [-Force]
 -Title <String> -Subtitle <String> [<CommonParameters>]
```

### NoInteractiveCountdown

```powershell
Show-ADTInstallationRestartPrompt [-NoInteractiveCountdown] [-ShutdownReasonText <String>] [-NoForceCloseApps]
 [-AllowMove] [-AllowCancel] [-CustomMessage] [-CustomMessageText <String>] [-NotTopMost] [-PersistPrompt]
 [-WindowLocation <DialogPosition>] [-Force] -Title <String> -Subtitle <String> [<CommonParameters>]
```

## DESCRIPTION

The `Show-ADTInstallationRestartPrompt` function displays a restart prompt with a countdown to a forced restart.
The prompt can be customized with a title, countdown duration, and whether it should be topmost.
Restarting without showing the prompt at all only ever happens when `-AllowSilentRestart` is specified.

## EXAMPLES

### EXAMPLE 1

```powershell
Show-ADTInstallationRestartPrompt -NoInteractiveCountdown
```

Displays a restart prompt without a countdown.

### EXAMPLE 2

```powershell
Show-ADTInstallationRestartPrompt -InteractiveCountdown 300
```

Displays a restart prompt with a 300-second countdown.

### EXAMPLE 3

```powershell
Show-ADTInstallationRestartPrompt -InteractiveCountdown 600 -InteractiveCountdownNoHide 60
```

Displays a restart prompt with a 600-second countdown, removing the ability to hide/minimise the dialog for the last 60 seconds.

### EXAMPLE 4

```powershell
Show-ADTInstallationRestartPrompt -AllowSilentRestart -Force
```

Displays a restart prompt that allows silent restart if nobody is logged on, otherwise will force the prompt to appear regardless of the deployment session's deploy mode.
