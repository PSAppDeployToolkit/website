## PSADT v4.2.0 RC2

The second release candidate of PSAppDeployToolkit 4.2.0 is here! Thank you to everyone who tested RC1 and reported issues. This release addresses that feedback, and we invite all early adopters to continue testing before we hit general availability.
{/*truncate*/}

### Highlights

- `Show-ADTInstallationRestartPrompt` improvements:
  - Some parameters have been renamed to make their behaviour clearer (with previous names retained as aliases)
  - `-Force` switch support to show the prompt in Silent/NonInteractive mode
  - `-NoForceCloseApps` switch to omit the `/f` switch when calling `shutdown.exe` for more graceful restarts
  - Parameter sets fixed so that all UI options are still available when suppling `-AllowSilentRestart` (previously named `-SilentRestart`)
  - Default countdown durations can now be set in `config.psd1`.
- `New-ADTTemplate` can now rename the `Invoke-AppDeployToolkit` launcher files via `-LauncherName`, and omit content (Assets, Config, Extensions, Files, Module, Strings, SupportFiles) via `-ExcludeContent`.
- `Show-ADTInstallationPrompt -SecureInput` now returns the entered text as a `SecureString`.
- `Show-ADTInstallationWelcome -CheckDiskSpace` now works without an active deployment session.
- Group Policy now supports version-specific policy keys, so 4.2-only settings such as Base64 assets don't break 4.0/4.1 deployments on the same device.
- New `PathsBasedOnSystemContext` config option to use the `NoAdminRights` paths whenever the caller isn't the LocalSystem account, rather than whenever the caller isn't an admin.
- Numerous fixes to the v3 compatibility layer to better match v3 behaviour.
- Extensive new unit test coverage across the C# and PowerShell code.

You can find the full release notes [here](https://psappdeploytoolkit.com/docs/reference/release-notes).

Check the [upgrade guidance](https://psappdeploytoolkit.com/docs/how-to/upgrade-from-v4-1) for full details of any breaking changes.

### Download

Either download from [GitHub](https://github.com/PSAppDeployToolkit/PSAppDeployToolkit/releases), or install the pre-release from the PowerShell Gallery:

```powershell
Install-Module -Name PSAppDeployToolkit -Scope CurrentUser -AllowPreRelease
```

If this produces an error that the `-AllowPreRelease` parameter is not recognized, then first update **PowerShellGet** and then restart your PowerShell console:

```powershell
Install-Module PowerShellGet -Force -Scope CurrentUser
```

Please submit any issues via [GitHub](https://github.com/PSAppDeployToolkit/PSAppDeployToolkit/issues).
